About this test

A dead pixel is a tiny dot that never lights up, while a stuck pixel stays locked on one color. Both are easiest to see on a full-screen solid color. This tool fills your display with red, green, blue, white, black, yellow, cyan and magenta, one after another, and includes a gradient test for color banding.

How to use the dead pixel test

  1. Clean the screen with a soft dry cloth so dust is not mistaken for a pixel.
  2. Press Start color test and move through the colors with a click or the arrow keys.
  3. Look closely at every color, especially black and white. Note any odd dot, then press Esc to exit.
  4. Run the gradient test and check for visible stripes instead of a smooth blend.

Frequently asked questions

What is the difference between a dead pixel and a stuck pixel?

A dead pixel stays black on every color. A stuck pixel stays one color, such as red or green. Stuck pixels can sometimes be fixed, dead pixels usually cannot.

How many dead pixels are acceptable?

It depends on the manufacturer’s policy. Many brands allow a few on a panel, so check the warranty before you buy or return a screen.

What is backlight bleed?

It is light leaking around the edges of an LCD screen, most visible on a black screen in a dark room. A little is normal, strong bright patches are not.
