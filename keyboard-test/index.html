About this test

This keyboard tester shows every key you press on an on-screen layout. Pressed keys turn bright, and keys you already tested stay blue, so any key that never lights up is easy to spot.

How to use the keyboarder test

  1. Click the page once so the browser sends keystrokes to it.
  2. Press every key, including function and arrow keys. Tested keys turn blue.
  3. Hold three or more keys together to see whether your keyboard registers all of them.
  4. Press Reset to start again.

Frequently asked questions

Why do some keys not show up?

Keys such as Fn, volume and media buttons are often handled by firmware and never reach the browser. The key may still work.

What is keyboard ghosting?

Ghosting happens when a keyboard fails to register some keys pressed at the same time. Gaming keyboards with n-key rollover avoid it.

Will this tool record what I type?

No. Keystrokes are processed in your browser only and are never stored or sent anywhere.
