Before you pay, test these things

Do this in daylight with the seller present. It takes about ten minutes and can save you from an expensive mistake.

  • Screen: run the dead pixel test and look for stuck pixels, dark patches and uneven backlight.
  • Refresh rate: confirm the advertised speed with the refresh rate test.
  • Keyboard and trackpad: press every key in the keyboard tester and click both trackpad buttons.
  • Audio: check both speakers with the speaker test and the microphone with the mic test.
  • Webcam: open the webcam test and check sharpness and color.
  • Battery and charger: check battery health in system settings and make sure the charger fits firmly.
  • Ports and Wi-Fi: plug in a USB device and connect to a network.
  • Ownership: ask for a receipt and make sure the device is signed out of the previous owner’s account.

If anything fails, negotiate the price or walk away.
