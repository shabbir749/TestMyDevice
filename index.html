Tips for buying a used phone or laptop

  • Run the color test in a dim room to find dead pixels and tints.
  • Check that the refresh rate matches the listing.
  • Test both speakers, the microphone and the front camera.
  • On laptops, press every key and test the trackpad.

Frequently asked questions

Is TestMyDevice safe and private?

Yes. Every test runs locally in your browser. Audio, video and keystrokes are never uploaded or stored.

Why does the browser ask for camera or microphone permission?

Browsers require your explicit permission before a page can use them. Click Allow to run the test and revoke it any time in site settings.

Can I use these tools to check a used phone or laptop?

Yes. Open the site in the device browser and run the screen, audio, keyboard and webcam tests while meeting the seller.
